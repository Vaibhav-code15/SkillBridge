# v1.0.0 release notes — draft

Do not publish until review, integration and final verification are complete. No tag or release has been created.

- Student applications support withdrawal, reapplication, decisions, history and notifications.
- Recommendations, skill improvement suggestions and faculty team skill-gap analysis build on the explainable matching engine.
- Administrators can view aggregates, manage account access and remove or restore opportunities; expired opportunities close after their deadline and profile completeness is visible to students.

Production deployment and PostgreSQL compatibility remain unverified. Desktop and mobile visual acceptance still requires human review. Sprint 3 stories remain pending final review and integration.
