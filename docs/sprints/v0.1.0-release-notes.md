# v0.1.0 release notes — draft

Publish only after review and merge; no release or tag has been created.

- Students and faculty can register and sign in; students maintain profiles, skills, projects and certifications.
- Faculty manage opportunities and configure required skill levels and importance weights. Administrators manage the skill catalogue.
- The local development setup includes a Tailwind build, guarded fictional demo data and automated checks.

Authentication uses usernames rather than the earlier planned email login. Faculty accounts are not institutionally verified. Visual review, PostgreSQL compatibility and production deployment configuration remain unverified. Matching, applications and recommendations are future-sprint work.
