# v0.2.0 release notes (draft)

Draft for the Sprint 2 pull request; publish only after review and integration. No release or tag has been created.

- Students can browse, search and filter published opportunities that are still open, and see how their current skills compare with requirements.
- Students can submit one application per opportunity. Application is available through the deadline date; expired items are not automatically closed.
- Faculty can review applicants for opportunities they own, including student profile details, current fit scores and per-skill explanations.
- Matching uses exact weighted fractional credit and half-up integer rounding. Applicant ties resolve by application time, case-insensitive name and application ID.
- The local demo seed includes fictional applications and the CI suite covers the matching package.

Matching recommendations, withdrawals, shortlisting, notifications, reports and other Sprint 3 stories remain upcoming. Authentication remains username-based. Production deployment and PostgreSQL compatibility have not been verified.
